Setup notes (for whoever maintains this site)

This page is wired for Google Sheets but currently runs in local demo mode (see APPS_SCRIPT_URL and DEMO_MODE near the top of the script). It needs a companion Apps Script (AppsScript-Code.gs) deployed as a web app inside a Google Sheet — once deployed, paste its URL in and set DEMO_MODE = false. The board will then read/write real shared data — drafts, edit codes, photo uploads to Drive, and posted listings — instead of this tab's memory. Listings refresh automatically every 15 seconds so other people's posts show up without a manual reload.
